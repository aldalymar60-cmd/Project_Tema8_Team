# C++/Qt тестовый клиент

Данный каталог содержит тестовый клиент на C++/Qt для проверки работы серверной части проекта.

Клиент подключается к серверу по TCP:

127.0.0.1:5555

и отправляет JSON-запросы:

- ping
- register
- login
- sha512
- rsa
- bisection
- shortest_path
- history

Тестовый клиент нужен для демонстрации механизма связи клиент-сервер без использования Python.

## Запуск

Сначала запустить сервер:

cpp_server/Tema8CppServer.pro

Затем запустить клиент:

cpp_test_client/Tema8CppTestClient.pro
