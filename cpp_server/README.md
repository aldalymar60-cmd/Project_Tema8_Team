# C++/Qt сервер проекта Tema 8

Данный каталог содержит серверную часть проекта, реализованную на языке C++ с использованием Qt.

## Технологии

- C++17
- Qt Core
- Qt Network
- Qt SQL
- QTcpServer / QTcpSocket
- JSON
- SQLite
- Singleton для работы с базой данных

## Функционал сервера

Сервер принимает JSON-запросы по TCP на порту 5555 и обрабатывает команды:

- ping — проверка соединения
- register — регистрация пользователя
- login — авторизация пользователя
- sha512 — вычисление SHA-512
- rsa — демонстрационное RSA-шифрование
- bisection — метод деления пополам
- shortest_path — поиск кратчайшего пути алгоритмом Дейкстры
- history — история выполненных операций

## Запуск

Открыть проект в Qt Creator:

cpp_server/Tema8CppServer.pro

Выбрать комплект сборки:

Manual UCRT64 Qt6

После запуска сервер ожидает JSON-запросы на адресе 127.0.0.1 и порту 5555.
