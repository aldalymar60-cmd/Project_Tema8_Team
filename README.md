# Project_Tema8_Team

## Тема проекта

Тема №8: RSA, SHA-512, метод деления пополам и поиск кратчайшего расстояния между вершинами графа.

2. Альдали Аммар — реализация алгоритмов RSA, SHA-512 и метода деления пополам.
3. Алали Мохаммад — разработка клиентской части, подготовка диаграмм, README и тест-плана.

## Цель проекта

Цель проекта — разработать клиент-серверное приложение, которое выполняет криптографические, численные и графовые алгоритмы по теме №8.

Приложение позволяет пользователю отправлять запросы клиентом на сервер, получать результат выполнения выбранной операции и сохранять историю операций в базе данных SQLite.

## Функциональные возможности

Приложение реализует следующие функции:

1. Шифрование данных с помощью RSA.
2. Вычисление SHA-512 хэша для введённого текста.
3. Нахождение корня уравнения методом деления пополам.
4. Поиск кратчайшего расстояния между вершинами графа.
5. Сохранение истории операций в базе данных.
6. Использование шаблона проектирования Singleton.
7. Клиент-серверное взаимодействие.
8. Запуск проекта через Docker.

Инструкция по запуску
Запуск без Docker
Клонировать репозиторий:
git clone https://github.com/aldalymar60-cmd/Project_Tema8_Team.git
Перейти в папку проекта:
cd Project_Tema8_Team
Установить зависимости:
pip install -r requirements.txt
Запустить сервер:
python server/server.py
В другом терминале запустить клиент:
python client/client.py
Для запуска оконного интерфейса клиента:
    python client/client_gui.py
### Запуск через Docker

Для запуска проекта через Docker необходимо выполнить команду:

docker-compose up --build

После запуска сервер будет доступен по адресу:

http://127.0.0.1:5000
Пример работы приложения

Пользователь запускает клиентскую часть и выбирает одну из операций:

1. RSA Encrypt
2. SHA-512
3. Bisection method
4. Shortest path

После выбора операции клиент отправляет запрос на сервер. Сервер выполняет операцию, сохраняет результат в базу данных и возвращает ответ клиенту.

База данных

В проекте используется база данных SQLite.

В базе данных сохраняется история выполненных операций:

название операции;
входные данные;
результат;
дата и время выполнения.
Singleton

В проекте реализован шаблон проектирования Singleton.

Singleton используется для хранения конфигурации сервера. Это позволяет создать только один экземпляр класса конфигурации и использовать его в разных частях программы.
