# Описание проекта

## Название проекта

Project_Tema8_Team

## Тема

Тема №8: RSA, SHA-512, метод деления пополам и поиск кратчайшего расстояния между вершинами графа.

## Краткое описание

Проект представляет собой клиент-серверное приложение, разработанное на языке Python.

Клиент отправляет запросы на сервер, сервер выполняет выбранную операцию и возвращает результат пользователю.

## Реализуемые функции

1. Шифрование и расшифрование данных с помощью RSA.
2. Вычисление SHA-512 хэша.
3. Нахождение корня уравнения методом деления пополам.
4. Поиск кратчайшего расстояния между вершинами графа.
