# Тест-план проекта

Цель тестирования — проверить корректность работы основных функций клиент-серверного приложения.

| 2 | SHA-512 | text = hello | Возвращается SHA-512 хэш | Pass |
| 3 | Метод деления пополам | a = 1, b = 3, epsilon = 0.0001 | Корень уравнения приблизительно равен 2 | Pass |
