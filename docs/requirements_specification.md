# Спецификация требований

## 1. Назначение проекта

Проект представляет собой клиент-серверное приложение по теме №8.

Приложение предназначено для выполнения криптографических, численных и графовых алгоритмов.

## 2. Функциональные требования

Система должна выполнять следующие функции:

1. Шифрование данных с помощью RSA.
2. Расшифрование данных с помощью RSA.
3. Вычисление SHA-512 хэша для введённого текста.
4. Нахождение корня уравнения методом деления пополам.
5. Поиск кратчайшего расстояния между вершинами графа.
6. Сохранение истории операций в базе данных SQLite.
7. Обработка запросов клиента на сервере.
8. Использование шаблона Singleton.
9. Запуск проекта через Docker.

## 3. Нефункциональные требования

1. Приложение должно быть написано на языке Python.
2. Серверная часть должна использовать Flask.
3. Данные должны сохраняться в SQLite.
4. Проект должен быть размещён на GitHub.
5. Проект должен содержать README, Wiki, диаграммы и тест-план.
6. Код должен быть структурирован по папкам.
7. Проект должен поддерживать запуск через Docker.

## 4. Требования к клиенту

Клиент должен позволять пользователю выбрать одну из операций:

- RSA;
- SHA-512;
- метод деления пополам;
- поиск кратчайшего пути.

Клиент отправляет запрос на сервер и получает результат.

## 5. Требования к серверу

Сервер должен:

- принимать HTTP-запросы;
- определять выбранную операцию;
- вызывать нужный алгоритм;
- сохранять результат в базу данных;
- возвращать ответ клиенту.

## 6. Требования к базе данных

База данных должна хранить:

- название операции;
- входные данные;
- результат;
- дату и время выполнения операции.

## 7. Требования к тестированию

Проект должен содержать тест-план и UnitTest для проверки Singleton.
